# bangla-spellcheck-dict

বাংলা স্পেল চেকারের জন্য শব্দতালিকা — **৮৩,৫৮৩** ইউনিক শব্দ।

## উৎস
- **Banan Andolon (বানান আন্দোলন) dictionary app** — ৫০,৩৯৬ পরিষ্কার headword (`(অশুদ্ধ)` ট্যাগযুক্ত ভুল-বানান এন্ট্রি বাদে)
- **LibreOffice Bengali hunspell dictionary (bn_BD)** — ৮০,১৬৯ root (open source: LGPL/GPL/MPL)

দুটোর ইউনিয়ন, ডিডুপ্লিকেট করা। শুধু headword/বানান নেওয়া হয়েছে (অর্থ/সংজ্ঞা নয়)।

## ফাইল
- `words.txt` — ৮৩,৫৮৩ সঠিক বাংলা শব্দ (প্রতি লাইনে একটি)
- `wrong-words.txt` — ৫,৭১৭ প্রচলিত ভুল বানান (সাজেশন জোড়া বানানোর কাঁচামাল)

## ব্যবহার
স্পেল চেকারের ডিকশনারি হিসেবে `words.txt` লোড করুন।
